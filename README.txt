ЦВЕТНЫЕ ПАЗЫ — игра на HTML, CSS, JavaScript

Откройте index.html в браузере на компьютере.
Для публикации на телефоне через GitHub Pages:
1. Создайте публичный репозиторий, например color-grooves.
2. Загрузите в корень репозитория файлы index.html, style.css, script.js.
3. В настройках репозитория: Settings -> Pages -> Build and deployment -> Deploy from a branch.
4. Выберите main и /(root), сохраните.
5. Откройте опубликованную ссылку на телефоне.

Правила: перетаскивать фишки пальцем или мышью, через верхний горизонтальный паз
переводить фишки между пятью столбцами. Разложить по рядам как цвета слева.

Вторая версия «Цветные_пазы_игра.html» содержит всю игру в одном файле:
её можно открывать на компьютере без остальных файлов.
